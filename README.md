### Tentang Saya

**Fokus Saat Ini:** Sedang mendalami pengembangan aplikasi mobile dengan **Flutter** / **React Native** dan merancang backend yang kokoh menggunakan **Laravel**.
**Eksplorasi Data:** Suka mengulik dataset, melatih model **Machine Learning**, dan menganalisis metrik evaluasinya.
**Cyber Security:** Tertarik dengan dunia *Digital Forensics* dan sesekali suka mencari celah keamanan lewat tantangan **CTF (Capture The Flag)**.
**Selingan:** Di luar coding, saya biasa mendesain UI/UX di **Figma** atau bermain dengan simulasi logika hardware untuk **IoT**.
